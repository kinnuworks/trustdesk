# Orrin Freight Security Handbook

Synthetic document for a fictional company, used for demonstration only.

## Program
Orrin Freight runs a small security program for its logistics software. The program covers the customer-facing routing platform and the production cloud account. Internal office IT and HR systems are managed separately by an outside IT provider and are outside the scope of this handbook.
The VP of Engineering is accountable for security. There is no dedicated security team.

## Policies and audits
This handbook is reviewed every two years.
Engineering leads run an internal self-assessment of the platform once a year.
Orrin Freight has not yet completed an independent third-party audit. A first SOC 2 Type I audit is planned.

## Training
New employees complete security awareness training when they join. There is no recurring annual training at present.

## People
Orrin Freight does not perform background checks.
Access for leavers is removed by the outside IT provider when HR notifies them. No time limit is set for this.
